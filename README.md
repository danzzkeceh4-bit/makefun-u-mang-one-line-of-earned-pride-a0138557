# One Line of Earned Pride

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557)

One line of earned pride — a quiet moment, seventy-three years in the making:

> At seventy-three, my grandmother threaded the needle on the first try, then sewed the button back onto my father's coat without looking up.

No trophy, no podium, no speech. Just a grandmother, a needle, and a button
sewn back onto her son's coat on the first try — without looking up. The pride
is in the hands, not in the words: decades of practice, landing in a single
unhurried gesture.

## How it works

`main.py` (Python 3.13, standard library only) writes that one line — 139
characters, no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), exactly as the competition requires.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
